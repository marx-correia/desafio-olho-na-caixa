# Como organizar sua submissão

Envie o link do seu repositório (público ou com acesso liberado para a banca) contendo:

```
seu-repositorio/
  codigo/                    → código-fonte completo
  README.md                  → instruções de instalação e execução (a banca precisa conseguir rodar)
  documento/
    documento_submissao.pdf  → até 6 páginas (use o template documento_template.md como base)
  video/
    demonstracao.mp4         → até 5 minutos, ou link para vídeo não listado (YouTube/Drive)
  material-de-captura/
    fotos-videos-usados-na-medicao/
    quantidade-real-e-como-foi-apurada.csv
```

## Checklist antes de enviar

- [ ] Atende pelo menos 2 dos 4 itens obrigatórios (banana, tangerina, tomate, cenoura)?
- [ ] Documento cobre as 3 dimensões: processo de captura, evidências da abordagem, PoC funcional?
- [ ] Margem de erro declarada **para cada item atendido**, com método de cálculo (quantos lotes testados, como obteve o valor real, qual métrica de erro)?
- [ ] Limites conhecidos da solução estão descritos?
- [ ] Código roda com as instruções fornecidas, sem depender de hardware não permitido?
- [ ] Vídeo mostra o protótipo funcionando sobre material real (não é uma tela estática/slide)?
- [ ] Material de captura usado na medição de acurácia está incluído, com a quantidade real de cada lote e como foi apurada?
- [ ] Nenhuma criança aparece nas imagens; rostos de adultos estão com consentimento ou desfocados?
